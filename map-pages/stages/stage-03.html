二、复用规则（只改内容，不改设计）

  1. 只修改文件顶部 var BOARD = { ... } 里的取值字段内容。
  2. 不要改 CSS、字号、颜色、版面布局与动效。
  3. 内容过多时的默认行为：流程图按可用空间等比缩放、四边留白 ≥3mm；两个 ❓ 列表默认显示 6 条，其余折叠为「展开全部 N 条 ▾」。
  4. 改完直接打开文件即可，无需其它调整；换一行数据即换一张板块图。
  5. 右下角「说明 / 源码」是交付入口（仅用于查看字段映射与源码），正式使用时可直接删除该按钮与抽屉代码，不影响看板。

四、交互与动效

  • 流程图胶囊：悬停放大 1.5 倍并置顶（不透明底 + 阴影）；有链接显示点入链接斜线箭头（默认橙、点击绿）
  • 分支胶囊：红色边框，整块可点展开 / 收起分支行，展开与按下时三角变绿；展开行用虚线连接主干

三、JS 关键函数

函数作用
applyBoard()把 BOARD 写入版面：序号/阶段/环节名称、两条横幅、链路、两个列表、子流程数
applyFlow() / RB.flow()解析「流程图提示语」字段，生成子流程行、节点、分支行与点入链接，套用模板图标与配色
build() / layout()生成节点并按行定位，计算行号、行高与内容尺寸
normalize()胶囊固定 168×80px、内容自动换行；仍超出高度时自动递减字号（12.5px→7px），保证文字全部展示
fit()整张流程图按可用宽高等比缩放（上限 1.25），高度方向居中，四边留 ≥3mm
draw()绘制节点之间的连接线：主干为实线、分支行为虚线
show() / hide()全屏放大：把同一块面板搬进浮层（非克隆），关闭后搬回，展开分支与拖拽均可正常使用
